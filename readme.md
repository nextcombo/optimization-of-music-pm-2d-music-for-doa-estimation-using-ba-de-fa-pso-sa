# Optimization of MUSIC, PM, 2D-MUSIC for DOA Estimation using BA, DE, FA, PSO, SA

Direction of Arrival (DOA) estimation is an important research direction in array signal processing. Methods for DOA estimation based on array signal processing can achieve high-resolution direction estimation for multiple signal sources at different directions simultaneously, which are widely applied in various research fields such as radar, sonar, active protection systems, communication systems, and intelligent antennas. Maximum Likelihood Estimation (MLE) is one of the most important and widely used methods in statistical estimation theory. In theory, MLE can achieve optimal performance, but the algorithm for implementing this estimation needs to perform a global search for multivariable nonlinear maximum values, which has a large computational burden. This is precisely the bottleneck issue with the application of MLE methods. The main application objects of computational intelligence methods are difficult optimization problems. Therefore, based on the actual situation in non-cooperative parameter estimation, this paper appropriately applies Particle Swarm Optimization Algorithm (PSO), Differential Evolution Algorithm (DE), Firefly Algorithm (FA), Bat Algorithm (BA), and Simulated Annealing Algorithm (SA) to optimize the grid search process for the difficult optimization problem of DOA estimation using MUSIC, PM, 2D-MUSIC algorithms.
